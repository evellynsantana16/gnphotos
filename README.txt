# 📸 GN Photos | Portfólio de Fotografia

Site institucional desenvolvido para apresentar o trabalho do fotógrafo **Gabriel Nascimento**, reunindo seus principais ensaios e registros em um ambiente moderno, responsivo e de fácil navegação.

O projeto foi pensado para transmitir profissionalismo, credibilidade e destacar a qualidade do trabalho através de uma galeria organizada por categorias, permitindo que clientes conheçam diferentes estilos de fotografia em poucos cliques.

## ✨ Funcionalidades

* Página inicial moderna e responsiva;
* Portfólio organizado por categorias:

  * Casamentos;
  * Ensaios;
  * Retratos;
  * Infantil;
  * Esportivo;
  * Shows;
* Galeria de imagens em alta qualidade;
* Informações sobre o fotógrafo;
* Botão de orçamento via WhatsApp;
* Link direto para o Instagram;
* Layout otimizado para computadores, tablets e celulares.

## 🛠️ Tecnologias

* HTML5
* CSS3
* JavaScript
* Bootstrap
